PYTHON BASICS

Бүрэн давтах тэмдэглэл (Full Revision Notes)

1 PYTHON ГЭЖ ЮУ ВЭ? (WHAT IS PYTHON?)
  • Python бол өндөр түвшний, хөрвүүлэгддэг (interpreted), ерөнхий зориулалтын програмчлалын хэл юм.
  • Анх Гвидо ван Россум (Guido van Rossum) зохиосон.
  • Веб хөгжүүлэлт, автоматжуулалт, дата сайнс, хиймэл оюун (AI), скрипт бичих болон программ хангамж хөгжүүлэлтэд ашиглагддаг.
  • Анхлан суралцагчид дурладгийн учир: ойлгомжтой синтакс, уншихад хялбар код, асар баялаг сангийн дэмжлэг, олон платформ дээр ажиллах чадвар.
2 ГОЛ ОНЦЛОГУУД (KEY FEATURES OF PYTHON)
  • Унших болон бичихэд хялбар (Easy to read and write)
  • Хөрвүүлэгддэг хэл (Interpreted language)
  • Динамик төрөлтэй (Dynamically typed)
  • Объект хандалтат болон функциональ програмчлалын дэмжлэгтэй
  • Өргөн уудам стандарт сан (Large standard library)
  • Windows, macOS болон Linux дээр жигд ажилладаг
3 СИНТАКСЫН ҮНДСЭН ДҮРЭМ (BASIC SYNTAX RULES)
  • Python нь том, жижиг үсгийг ялгадаг (case-sensitive).
  • Кодын блокийг тодорхойлоход зайн догол мөр (indentation) ашигладаг.
  • if, for, while, def гэх мэт бүтцийн ард хоёр цэг (:) тавина.
  • Тайлбар (comments) нь # тэмдэгтээр эхэлнэ.
  • Олон мөрт тайлбар эсвэл текстийг гурвалсан хашилтаар (""" эсвэл ''') бичнэ.
  • Үр дүнг дэлгэцэнд хэвлэхдээ print() функцийг ашиглана.
print("Hello, Python!")
4 ТҮЛХҮҮР ҮГС БА НЭРШИЛ (KEYWORDS & IDENTIFIERS)
  • Keywords: Хэлэнд урьдчилан тусгайлан зориулагдсан үгс.
  • Identifiers: Хувьсагч, функц, класс зэрэгт хөгжүүлэгчийн өгсөн нэршил.

5 ХУВЬСАГЧИД (VARIABLES)

Тодорхойлолт: Хувьсагч нь санах ойд утгыг хадгалдаг нэгж юм.

  • Python нь динамик төрөлтэй (өгөгдлийн төрлийг урьдчилж зарлах шаардлагагүй).
  • Утга оноох оператор нь = юм.
x = 10
name = "Alice"
price = 19.99
is_active = True
Жижиг санамж (Mini Notes):
• Олон хувьсагчид зэрэг утга өгөх: a, b = 5, 10
• Олон хувьсагчид ижил утга өгөх: x = y = z = 0
• Утга хооронд нь солих (Swapping): a, b = b, a
• Тогтмол утгын нэршлийн дүрэм: PI = 3.14 (Том үсгээр)

🛒 Бодит амьдралын жишээ: cart_total = 99.99 нь дэлгүүрийн нийт төлбөрийн дүнг хадгална.

PYTHON LISTS

Жагсаалттай ажиллах бүрэн лавлах

1 ТОДОРХОЙЛОЛТ (DEFINITION)
  • Python дахь List нь эрэмбэлэгдсэн, өөрчлөх боломжтой (mutable) цуглуулга юм.
  • Ямар ч өгөгдлийн төрлийг агуулж болох ба давхардсан утга зөвшөөрөгдөнө.
  • Дөрвөлжин хаалтан дотор [ ] бичигдэнэ.
my_list = [10, "python", 3.14, True]
# int, str, float, bool
2 ГОЛ ОНЦЛОГУУД (KEY FEATURES)
  • Ordered (Эрэмбэлэгдсэн): Элементүүдийн дарааллыг хэвээр хадгална.
  • Mutable (Өөрчлөгддөг): Элементийг өөрчлөх, нэмэх, хасах боломжтой.
  • Allows Duplicates: Ижил утга олон дахин орж болно.
  • Heterogeneous: Төрөл бүрийн өгөгдлийн төрлийг зэрэг хадгална.
  • Dynamic Size: Шаардлагатай үед томорч, жижгэрнэ.
Бодит амьдралын жишээ:
• Дэлгүүрийн сагс ➔ Барааны жагсаалт
• Сурагчдын дүн ➔ [85, 90, 78, 92]
• Хөгжмийн тоглуулагч ➔ Дуунуудын жагсаалт
3 ЖАГСААЛТ ҮҮСГЭХ (CREATING LISTS)
empty_list = [] # Хоосон жагсаалт numbers = [1, 2, 3, 4, 5] # Бүхэл тоон жагсаалт mixed = [1, "hello", 3.5, True]# Холимог өгөгдлийн төрөл duplicates = [1, 2, 2, 3, 1] # Давхардсан утгатай nested = [1, 2, [3, 4], "hi"] # Дотроо жагсаалт агуулсан (Nested)
4 ЭЛЕМЕНТЭД ХАНДАХ (ACCESSING ELEMENTS)
  • Indexing: Ганц элементэд хандах.
  • Slicing: Хэсэг бүлэг элементэд хандах.
Эерэг индекс:   0   1   2   3   4   5
Сөрөг индекс: -6  -5  -4  -3  -2  -1
Жагсаалт:    [10, 20, 30, 40, 50, 60]
my_list[0] ➔ 10 my_list[-1] ➔ 60 (сүүлчийнх) my_list[3] ➔ 40 my_list[-3] ➔ 40 my_list[1:4] ➔ [20, 30, 40] (эхлэл : төгсгөл) my_list[:3] ➔ [10, 20, 30] my_list[3:] ➔ [40, 50, 60] my_list[::2] ➔ [10, 30, 50] (2 алхмаар алгасах)

Санамж: start : end : step (end индекс өөрөө орохгүй)

6 ЖАГСААЛТЫН АРГУУД (METHODS QUICK VIEW)

Цээжлэх арга: A I E R P C S

  • append(x) ➔ төгсгөлд нь x-ийг нэмэх
  • insert(i, x) ➔ i индекст x-ийг оруулах
  • extend(it) ➔ бүх элементийг залгаж нэмэх
  • remove(x) ➔ хамгийн эхний x утгыг устгах
  • pop(i) ➔ i индекс дэх утгыг сугалж устгах
  • clear() ➔ бүх элементийг бүрэн арилгах
  • index(x) ➔ хамгийн эхний x утгын индексийг буцаах
  • count(x) ➔ x утга хэдэн удаа давтагдсаныг тоолох
  • sort() ➔ жагсаалтыг өсөхөөр эрэмбэлэх
  • reverse() ➔ жагсаалтын байрыг урвуулах
7 LIST COMPREHENSION (БОГИНО БИЧИГЛЭЛ)

Жагсаалтыг богино, ойлгомжтой үүсгэх гоёмсог арга.

new_list = [ expression for item in iterable if condition ]

Жишээнүүд:

squares = [x**2 for x in range(5)] # ➔ [0, 1, 4, 9, 16] even = [x for x in range(10) if x % 2 == 0] # ➔ [0, 2, 4, 6, 8]
💡 Зөвлөмж: Богино жагсаалтад тохиромжтой, кодыг маш цэвэрхэн болгодог!
8 ЧУХАЛ САНАМЖУУД (IMPORTANT POINTS)
  • Жагсаалт нь mutable тул өөрчлөлт анхны жагсаалтад шууд нөлөөлнө.
  • Индекс нь 0-ээс эхэлдэг.
  • Slicing хийхэд төгсгөлийн индекс өөрөө орохгүй.
  • Олон янзын өгөгдлийг нэг жагсаалтад хольж хадгалж болно.
  • Бэлэн аргуудыг (methods) ашиглах нь илүү хурдан бөгөөд хялбар.
💡 Санах ойлголт: Жагсаалт нь өөрөө томрох, жижгэрэх чадвартай, юуг ч хийж болдог савтай адил!

PYTHON TUPLES

Өөрчлөгддөггүй цуглуулга (Tuples)

1 ТОДОРХОЙЛОЛТ (DEFINITION)
  • Python дахь Tuple нь эрэмбэлэгдсэн, өөрчлөх боломжгүй (immutable) цуглуулга юм.
  • Элементүүд нь дурын төрлийн өгөгдөл байж болно.
  • Давхардсан утгыг зөвшөөрнө.
  • Дугуй хаалтаар ( ) бичигдэнэ.
my_tuple = (10, "Python", 3.14, True)
2 ГОЛ ОНЦЛОГУУД (KEY FEATURES)
  • ✔️ Ordered: Оруулсан дарааллыг хэвээр хадгална.
  • ✔️ Immutable: Үүсгэсний дараа өөрчлөх, нэмэх, хасах боломжгүй.
  • ✔️ Allows duplicates: Ижил утга давхардаж болно.
  • ✔️ Can store mixed data types: Төрөл бүрийн өгөгдөл хольж болно.
  • ✔️ Faster and lighter: Ихэнх тохиолдолд жагсаалтаас хурдан бөгөөд хөнгөн.
Бодит амьдралын жишээ:
• RGB өнгө = (255, 0, 0)
• Байршлын координат = (28.61, 77.21)
• Амралтын өдрүүд = ("Sat", "Sun")
3 ТАБЛЬ ҮҮСГЭХ (CREATING TUPLES)
empty_tuple = () nums = (1, 2, 3, 4) mixed = (1, "hello", 3.5, True) single = (5,) # ⚠️ Ганц элементтэй табль үүсгэхэд таслал заавал шаардлагатай! nested = (1, 2, (3, 4), "hi")
4 ЭЛЕМЕНТЭД ХАНДАХ (ACCESSING ELEMENTS)
  • Indexing: Ганц элементэд хандах.
  • Slicing: Хэсэг мужид хандах.
t = (10, 20, 30, 40, 50, 60)
Эерэг: 0, 1, 2, 3, 4, 5  |  Сөрөг: -6, -5, -4, -3, -2, -1
t[0] ➔ 10 t[-1] ➔ 60 t[1:4] ➔ (20, 30, 40) t[:3] ➔ (10, 20, 30) t[::2] ➔ (10, 30, 50)

Томьёо: t[index] эсвэл t[start:stop:step] (stop орохгүй)

6 ТАБЛИЙН АРГУУД (TUPLE METHODS)
  • count(x) ➔ x утга хэдэн удаа орсныг тоолно.
  • index(x) ➔ x утгын анх гарч ирсэн индексийг буцаана.
(1, 2, 2, 3).count(2) ➔ 2 ("a", "b", "c").index("b") ➔ 1
💡 Зөвлөмж: Табль нь өөрчлөгддөггүй (immutable) тул маш цөөхөн аргатай байдаг.
7 БАГЛАХ БА ЗАДЛАХ (PACKING & UNPACKING)
  • Packing: Олон утгыг нэг табль болгон баглах.
  • Unpacking: Таблийн утгуудыг хувьсагчдад салгаж оноох.
# Баглах (Packing) point = (4, 5) # Задлах (Unpacking) x, y = point # x = 4, y = 5 a, b, c = (1, 2, 3)
🧠 Санах арга: Packing = утгуудыг нэгтгэх, Unpacking = утгуудыг салгах.

9 ЧУХАЛ САНАМЖУУД (IMPORTANT POINTS)
  • Табль нь immutable тул элементийг шууд нэмэх, хасах, засах боломжгүй.
  • Ганц элементтэй үед ард нь таслал заавал тавина: (5,).
  • Дотроо өөр табль агуулж (nested) болно.
  • Элементүүд нь immutable байвал толь бичгийн түлхүүр (dictionary key) болгон ашиглаж болно.
  • Өгөгдлийг өөрчлөгдөхгүйгээр хамгаалахыг хүсвэл Tuple-ийг сонгоорой.
10 ШАЛГАЛТЫН ТОВЧ МЭДЛЭГ (EXAM TIPS)
  • ✔️ Tuple = дугуй хаалт ().
  • ✔️ Өөрчлөгдөх үү? Үгүй. Эрэмбэлэгдсэн үү? Тийм. Давхардал зөвшөөрөх үү? Тийм.
  • ✔️ Ганц элементтэй табль = (5,).
  • ✔️ Slicing хийхэд төгсгөлийн индекс өөрөө орохгүй.
  • ✔️ Үндсэн аргууд нь ердөө count() ба index().
11 СҮҮЛЧИЙН МИНУТЫН ДАВТАХ САНАМЖ (LAST-MINUTE REVISION)
✔️ Tuple = ordered + immutable + allows duplicates.
✔️ ( ) хаалтаар үүсгэнэ.
✔️ Индекс болон slicing ашиглан хандана.
✔️ Түгээмэл аргууд: count(), index().
✔️ Координат, RGB өнгө, тогтмол бүртгэлд хамгийн тохиромжтой.

PYTHON DICTIONARIES

Түлхүүр - Утгын хослол бүхий бүтэц

1 ТОДОРХОЙЛОЛТ (DEFINITION)
  • Python дахь толь бичиг нь түлхүүр-утгын (key-value) хослолоос бүрдсэн эрэмбэгүй/mapping цуглуулга юм.
  • Өөрчлөх боломжтой (Mutable).
  • Түлхүүрүүд нь цор ганц (давхардалгүй) байх ёстой.
  • Буржгар хаалтаар { } бичигдэнэ.
  • Утгууд нь (values) давхардаж болно.
my_dict = {"name": "Alice", "age": 21, "city": "NYC"}
2 ГОЛ ОНЦЛОГУУД (KEY FEATURES)
  • ✔️ Өгөгдлийг түлхүүр : утга байдлаар хадгална.
  • ✔️ Өөрчлөх, нэмэх, хасах боломжтой (Mutable).
  • ✔️ Түлхүүрүүд нь давтагдашгүй цор ганц байна.
  • ✔️ Түлхүүрээр маш хурдан хайж олдог (Fast lookup).
  • ✔️ Төрөл бүрийн өгөгдөл хадгална.
  • ✔️ Дотроо толь бичиг агуулж болно (Nested).
Бодит амьдралын жишээ:
• Оюутны анкет (Student record)
• Бүтээгдэхүүний дэлгэрэнгүй (Product details)
• Утасны лавлах (Phone contacts)
3 ТОЛЬ БИЧИГ ҮҮСГЭХ (CREATING DICTIONARIES)
empty_dict = {} student = {"name": "Sam", "marks": 90} mixed = {1: "one", "pi": 3.14, "active": True} nested = {"user": {"name": "Ana", "age": 22}}

PYTHON FUNCTIONS

Функц тодорхойлох ба ашиглах лавлах

1 ФУНКЦ ГЭЖ ЮУ ВЭ? (WHAT IS A FUNCTION?)
  • Функц нь тодорхой нэгэн ажлыг гүйцэтгэдэг дахин ашиглагдах кодын блок юм.
  • Код дахин давтагдахаас сэргийлж, кодыг уншиж ойлгоход хялбар болгодог.
  • Зөвхөн тусгайлан дуудсан үед л ажилладаг.
📖 Бодит амьдралын жишээ: Функцийг хоолны жортой зүйрлэж болно. Та жорыг нэг удаа бичээд хэрэгтэй үедээ хэдэн ч удаа дахин ашиглаж хоолоо хийж болно.
2 СИНТАКС (SYNTAX)
def function_name(parameters): """Docstring (Тайлбар - заавал биш)""" # кодын блок return value # буцаах утга - заавал биш
  • def нь функц тодорхойлох түлхүүр үг.
  • function_name нь нэршлийн дүрмийг баримтална.
  • parameters нь функцэд дамжуулах оролтын утгууд.
  • return нь тооцооллын үр дүнг дуудсан газарт буцаана.
3 ФУНКЦИЙН ТӨРЛҮҮД (TYPES OF FUNCTIONS)
  • Суурилагдсан (Built-in Functions): Python-д бэлэн байдаг функцууд: print(), len(), type().
  • Хэрэглэгчийн тодорхойлсон (User-defined Functions): Хөгжүүлэгч def түлхүүр үгээр өөрөө үүсгэсэн функцууд.
  • Ламбда функц (Lambda Functions): lambda түлхүүр үгээр бичигддэг жижиг нэргүй функцууд.
4 ФУНКЦ ҮҮСГЭХ БА ДУУДАХ
def greet(name): """Энэ функц хэрэглэгчтэй мэндчилнэ.""" print(f"Hello, {name}!") return "Done" # Функцийг дуудах greet("Alice") # Гаралт: Hello, Alice! result = greet("Bob") # Гаралт: Hello, Bob! print(result) # Гаралт: Done
💡 Санах зарчим: Нэг удаа тодорхойл, олон удаа ашигла (Define once, Use many times)!

10 ЧУХАЛ САНАМЖУУД (IMPORTANT POINTS)
  • Функц нь кодын дахин ашиглагдах чадварыг сайжруулдаг.
  • Функцийн нэршил тодорхой, учир утгатай байх ёстой.
  • Функцийг аль болох цомхон, зөвхөн нэг л зүйлийг хийдэг байхаар зохио.
  • Үр дүнг буцаахад return ашигла.
  • DRY зарчмыг баримтал: Don't Repeat Yourself (Өөрийгөө бүү давт).
11 СҮҮЛЧИЙН МИНУТЫН ДАВТАХ САНАМЖ
  • ✔️ def түлхүүр үгээр тодорхойлно.
  • ✔️ Нэрээр нь дуудаж ажиллуулна.
  • ✔️ Параметрүүд нь функцийн оролт болдог.
  • ✔️ *args = хувьсах дараалсан аргументууд.
  • ✔️ **kwargs = хувьсах түлхүүртэй аргументууд.
  • ✔️ Local scope дотор, Global scope гадна байна.

PYTHON IMPORT

Модуль болон сангуудыг холбох лавлах

1 ИМПОРТ ГЭЖ ЮУ ВЭ? (WHAT IS IMPORT?)
  • import нь Python-д бэлэн байгаа модулиудыг дуудаж ашиглахад хэрэглэгдэнэ.
  • Модуль гэдэг нь Python код (функц, класс, хувьсагч) агуулсан .py өргөтгөлтэй файл юм.
  • Энэ нь кодын зохион байгуулалт болон дахин ашиглалтыг дэмждэг.
🧰 Бодит амьдралын жишээ: Модулиудыг багажны хайрцаг дахь салангид багажууд гэж төсөөл. Та зөвхөн ажилдаа шаардлагатай байгаа тэр л багажаа сонгож авч ашигладаг.
2 СИНТАКС (SYNTAX)
import module_name from module_name import name1, name2, ... from module_name import * import module_name as alias from module_name import name as alias
  • module_name ➔ модулийн нэр (файлын нэр).
  • alias ➔ модуль эсвэл функцэд өгч буй товчилсон нэр (заавал биш).
3 ИМПОРТЫН ТӨРЛҮҮД (TYPES OF IMPORT)

2. Тодорхой зүйлсийг оруулахfrom module_name import name1, name2from math import sqrt, piЗөвхөн хэрэгтэй функцуудыг сугалж оруулна.
3. Бүгдийг шууд оруулахfrom module_name import *from math import *Бүх зүйлийг одоогийн кодонд шууд оруулна.
4. Модульд товч нэр өгөхimport module_name as aliasimport numpy as npМодульд богино товчилсон нэр онооно.

10 ЧУХАЛ САНАМЖУУД БА ДАВТАХ ЦЭГҮҮД

  • Сан нь урьдчилан бэлтгэсэн кодуудын (модуль, функц, класс) нэгдэл юм.
  • Python-ийн боломжуудыг асар ихээр тэлдэг.
  • Цаг хугацаа болон хүч хөдөлмөрийг хэмнэдэг.
  • Бид сангуудыг импорт хийж доторх функцуудыг нь шууд ашигладаг.
🧰 Бодит амьдралын жишээ: Сангуудыг багажны том цүнх гэж бод. Багаж болгоныг өөрөө шинээр хийхийн оронд бэлэн багажнуудыг ашиглан ажлаа хурдан гүйцэтгэнэ.

PYTHON FILE SYSTEM

Файлын систем ба файлтай ажиллах бүрэн лавлах

1 ФАЙЛЫН СИСТЕМ ГЭЖ ЮУ ВЭ?
  • Файлын систем гэдэг нь диск дээр файл, хавтсыг зохион байгуулах, хадгалах, хандах болон удирдах арга зам юм.
  • Python нь файл болон хавтастай ажиллах тусгай модулиудаар хангадаг.
  • Гол модулиуд: os, shutil, pathlib.
🗄️ Бодит амьдралын жишээ: Компьютерээ том бичгийн шүүгээ гэж төсөөл. Файлууд нь доторх бичиг баримтууд, харин хавтаснууд (folders) нь шүүгээний тасаг юм.
2 ЧУХАЛ МОДУЛИУД (MODULES)
  • os ➔ Үйлдлийн системтэй шууд харьцах.
  • os.path ➔ Файлын зам болон нэршилтэй ажиллах.
  • shutil ➔ Өндөр түвшний үйлдлүүд (хуулах, зөөх, хавтас бүхлээр нь устгах).
  • pathlib ➔ Объект хандалтат орчин үеийн, хялбар шийдэл.
💡 Анхлан суралцагчдад os нь түгээмэл байдаг бол орчин үеийн кодонд pathlib-ийг илүүд үздэг.
3 АЖИЛЛАЖ БУЙ ХАВТАС (WORKING DIRECTORY)

Таны Python скрипт яг одоо ажиллаж байгаа хавтас юм.

import os print(os.getcwd()) # Одоогийн ажиллаж буй хавтсыг буцаана # Гаралт: C:\Users\YourName\Projects
4 ФАЙЛ НЭЭХ ГОРИМУУД (FILE MODES)
ГоримТайлбар (Description)
rУнших (Read - анхдагч): Файл заавал өмнө нь байх ёстой.
wБичих (Write): Шинэ файл үүсгэнэ, байгаа бол хуучин агуулгыг дарж бичнэ.
aЗалгах (Append): Хуучин мэдээллийн төгсгөлд шинэ өгөгдлийг залгаж бичнэ.
xҮүсгэх (Create): Шинэ файл үүсгэнэ, байгаа бол алдаа өгнө.
bХоёртын горим (Binary): Зураг, аудио, PDF зэрэгт ашиглана.
tТекст горим (Text - анхдагч).
+Унших ба бичих хамтарсан горим.

Жишээнүүд: "r", "w", "a", "rb", "w+", "a+"

5 ТҮГЭЭМЭЛ ҮЙЛДЛҮҮД (OS MODULE)
ҮйлдэлФункц / СинтаксЖишээТайлбар
Ажиллаж буй хавтас авахos.getcwd()os.getcwd()Одоо байгаа хавтасны замыг буцаана.
Хавтас солихos.chdir(path)os.chdir("C:/data")Заасан хавтас руу шилжинэ.
Хавтас доторхыг харахos.listdir(path)os.listdir(".")Файл ба хавтаснуудын нэрсийн жагсаалт.

Олон хавтас угсруулан үүсгэхos.makedirs(path)os.makedirs("a/b/c")Доторх хавтаснуудыг цуг үүсгэнэ.
Хоосон хавтас устгахos.rmdir(path)os.rmdir("temp_folder")Зөвхөн хоосон хавтсыг устгана.
Файл устгахos.remove(path)os.remove("file.txt")Заасан файлыг устгана.
Нэр өөрчлөхos.rename(src, dst)os.rename("a.txt", "b.txt")Файл эсвэл хавтасны нэрийг солино.

Файл мөн эсэхos.path.isfile(path)os.path.isfile("a.txt")Файл мөн бол True.
Хавтас мөн эсэхos.path.isdir(path)os.path.isdir("data")Хавтас мөн бол True.
6 ФАЙЛТАЙ АЖИЛЛАХ СУУРЬ (BASIC FILE HANDLING)
# Файл нээх f = open("file.txt", "r") # Файл хаах (Заавал хийх ёстой!) f.close()

Файлаас унших:

f.read() # Бүх файлыг бүтнээр уншина f.readline() # Зөвхөн нэг мөрийг уншина f.readlines() # Бүх мөрийг жагсаалт (list) болгож уншина

Файлд бичих:

f.write("Hello\n") # Мөр бичих f.writelines(["Hi\n", "Bye\n"]) # Жагсаалтаар бичих

Хамгийн шилдэг туршлага (with ашиглах):

with open("file.txt", "r") as f: data = f.read() # with ашиглавал файл автоматаар хаагддаг!

import os os.path.join("C:/data", "file.txt") # C:/data/file.txt os.path.basename("C:/data/file.txt") # file.txt os.path.dirname("C:/data/file.txt") # C:/data
8 PATHLIB (ОРЧИН ҮЕИЙН ШИЙДЭЛ)
  • Python 3.4-өөс нэвтэрсэн.
  • Объект хандалтат бөгөөд маш хялбар бичиглэлтэй.
from pathlib import Path p = Path("C:/data/file.txt") p.exists() # оршин буй эсэхийг шалгах p.is_file() # файл мөн эсэх p.is_dir() # хавтас мөн эсэх p.name # файлын бүтэн нэр p.stem # файлын өргөтгөлгүй нэр p.suffix # өргөтгөл (.txt) p.parent # дээд хавтас # Зам залгахдаа / операторыг шууд ашиглана! p2 = p.parent / "new_folder" / "a.txt"
9 SHUTIL МОДУЛЬ (ДЭЭД ТҮВШНИЙ ҮЙЛДЭЛ)
ФункцХэрэглээ

10 АЖИЛЛАХ ДАРААЛАЛ БОДИТ ЖИШЭЭ (WORKFLOW)

Файлаас унших f = open("my-folder/hello.txt", "r") print(f.read()) f.close() # 4. Файлын нэрийг солих os.rename("my-folder/hello.txt", "my-folder/greet.txt") # 5. 11 ЧУХАЛ САНАМЖУУД БА СҮҮЛЧИЙН МИНУТЫН ДАВТЛАГА
✔️ Файл нээсэн бол заавал хааж занш (санах ойг чөлөөлөх).
✔️ Аюулгүй, цэвэр ажиллагаанд with open(...) as f: ашигла.
✔️ Windows замуудад r"C:\path" хэлбэрээр raw string ашиглаарай.
✔️ Файл дээр үйлдэл хийхээс өмнө os.path.exists()-ээр шалгаж байх.
✔️ Файл болон хавтасны (file vs directory) ялгааг сайн анхаар.
✔️ Файл, хавтас устгахдаа ялангуяа rmtree() дээр маш болгоомжтой бай.
